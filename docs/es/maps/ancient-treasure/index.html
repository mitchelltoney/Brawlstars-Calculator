Ancient Treasure

Dos plataformas laterales separadas, líneas de visión centrales abiertas y flancos con arbustos y plataformas de salto premian la movilidad, la visión y un ancla de largo alcance.

    Las redes de rieles conectan las plataformas laterales separadas, permitiendo toques rápidos y disputas de emergencia.
