# Spanish (es) translation guide — brawlcalculator.com

Audience: Spanish-speaking Brawl Stars players (Spain and Latin America, e.g. Peru). Write neutral
Spanish that reads naturally in both — the register of a good Spanish-language Brawl Stars guide:
concise, confident, gamer vocabulary, no stiff literal calques. Use "tú" if the reader is addressed.

Keep EXACTLY as written in English (never translate, never change spelling/case):
- Every name listed in the chunk's "protected" array (brawlers, gadgets, star powers, maps, modes).
- Any other capitalized in-game proper name: Super names, attack names, hypercharges, pets/summons/
  turrets (e.g. Scrappy, Bruce, Porters), and stat labels such as "CounterPower 19".
- Possessives move to Spanish word order: "Edgar's punches" → "los puñetazos de Edgar".

Rules: translate meaning faithfully — keep every claim, number and named mechanic; add nothing, drop
